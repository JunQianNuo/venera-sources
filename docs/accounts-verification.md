# 账号功能验证记录

适用版本：包子漫画 1.1.2、漫画1234 1.2.2。检查日期：2026-10-11。

## 依据

- Venera 的 [图源文档](https://github.com/venera-app/venera/blob/master/doc/comic_source.md) 与源码 `lib/comic_source/parser.dart`：普通登录返回成功后应用记录账号，网站书架使用 `favorites.loadComics` 与 `favorites.addOrDelFavorite`；操作失败必须抛出错误。
- 包子当前 `/user/signin` 页面及其公开 `signin.min.js`：登录接口为 `/api/bui/signin`，字段 `username`、`password`，成功令牌为 `TSID`。空字段请求返回 `ERR_MAIL`，确认 URL 编码表单被接受。页面脚本仍写入旧域名，图源改为当前入口域名。
- 包子当前漫画详情的收藏链接与已有接口实现：`set_bookmark`、`del_bookmark`、`/user/my_bookshelf`。匿名访问专属书架可能返回登录页面，也可能返回空书架；图源检查当前入口的 `TSID`，并单独识别、拒绝访客临时书架。
- 漫画1234当前公开 `mint.js`：`rend/isfav` 查询状态，`rend/favadd` 提交 `did` 和 `type=comic`，返回 `cid` 表示切换后的状态；公开脚本提供 `data-mint-page="shelf"`、`data-mint-shelf-item`、`mint-shelf-empty`、分页 `data-pages` 等标记。
- [MCCMS 源码](https://github.com/chshcms/mccms)：`sys/apps/controllers/api/User.php` 的会话接口、`api/Rend.php` 的收藏逻辑、`user/Fav.php` 的分页路径。当前漫画1234匿名 `user/info` 返回 `data.log=0`、`id=0`；匿名 `isfav` 也会返回“未收藏”，因此不能用它判断已登录。

## 自动化覆盖

`tests/accounts.test.cjs` 包含 20 项测试，覆盖图源注册前的配置解析、表单编码、令牌拒绝与安装域名、登录后的会话校验、退出登录、网站书架条目和空状态、推荐列表隔离、分页、登录失效、重复和并发收藏操作、未生效写入以及详情收藏状态。单条书架使用卡片自身为链接的结构，验证漫画 ID 和名称提取。另模拟 Venera GET 缓存，验证加入后立即刷新及取消收藏不读旧状态，并验证包子操作请求采用官网链接的 GET 方法，以及缺少登录 Cookie 时不将访客空书架当作有效会话。相同测试也用于生成后的发布脚本。

只读网络检查确认：两个图源对匿名会话均在校验阶段拒绝读取账号书架及收藏操作，没有请求收藏写入端点。

测试中的账号、令牌和书架条目为合成数据。真实账号书架 HTML 尚未观察，条目选择器基于公开脚本标记与既有结构，模拟测试通过不能证明实际账号页面完全兼容。

初版本地完整验证：40/40 源码与发布工具测试、34/34 发布脚本测试通过；生成物一致性和相对上一发布版本的版本递增检查通过。新增回归测试在修复前分别复现安装失败与书架漏读自身链接，修复后通过。

## 用户反馈后的修订

用户日志确认包子安装时在解析 `account` 配置阶段调用 `load_setting`，此时原生图源尚未注册，因此空值异常。1.1.1 将注册网页地址改为静态配置，其余请求仍在运行时读取所选入口。

漫画1234日志在收藏提交后读取书架时报告条目结构错误；用户确认新收藏已出现在网站书架。1.2.1 使条目解析同时检查自身链接和内部链接，并读取当前样式表定义的 `user-list__title`。公开 CSS/JS 确認书架条目标记和标题类名；卡片自身为链接的情况已用合成条目复现，真实私有 HTML 仍未取得。

包子随后报告收藏后的状态核对失败，用户确认网站书架没有新增条目。当前公开详情的收藏按钮为 `/user/operation_v2?op=set_bookmark&comic_id=...&chapter_slot=0` 的普通链接，1.1.2 改为与官网一致的 GET 请求，并保留写入前后核对。网站对真实账号写入的结果仍需用户验证，不能仅凭链接形式断言 POST 是唯一原因。

同时检查 Venera 的 [请求缓存源码](https://github.com/venera-app/venera/blob/master/lib/network/cache.dart)，确认五秒内直接复用 GET，`cache-time: no` 可绕过缓存。模拟该行为后，两个图源的加入后刷新测试均在修复前失败。1.1.2/1.2.2 为书架、收藏状态、会话及账号权限查询禁用缓存；公开阅读请求保持原有策略。

禁用缓存后的匿名检查发现，包子也可返回“专属书架为空”的 HTML。1.1.2 在读取书架前检查当前入口是否有非空 `TSID`，缺少时提示重新登录。Cookie 存在仅是必要条件，不能证明服务器仍认可会话；仍保留登录页面识别和写入后的书架核对，真实账号结果需要在 Venera 验证。

1.1.2/1.2.2 修订完整验证：46/46 源码与发布工具测试、40/40 发布脚本测试通过，生成物一致性、版本递增及独立代码审查通过。匿名只读检查确认两个图源均拒绝收藏且未请求写入端点。

## 需要在 Venera 中验证

更新图源后自行登录，确认网站书架完整加载；1234 收藏较多时确认后续页面。用一部原本未收藏的漫画验证加入与取消，并在网站核对。检查已有漫画的收藏标记。密码和 Cookie 不应发送给维护者或上传 GitHub。

浏览器自动控制本次连续超时，未取得真实账号验证结果。代码不会自动购买章节，也不会自动合并本地收藏或同步阅读进度。
