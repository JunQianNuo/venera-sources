# Venera 图源仓库设计

目的：托管已有的包子漫画和漫画1234图源，使修复、验证和更新可重复执行。

- `sources/*.js` 是图源源码，保留 `baozi_fixed`、`mh1234_fixed` 的 key。迁移到仓库后的版本分别为 1.0.1、1.1.1。
- `repository.json` 保存 GitHub 的 `owner/repo`、分支和图源说明。默认分支 main；未配置账号时只能本地导入。
- `scripts/build.cjs` 读取源码中的 name/key/version/minAppVersion，生成 `dist/*.js` 和根目录 `index.json`。配置仓库后自动写入脚本的更新 URL，索引使用绝对 URL，同时保留 fileName。
- 测试使用精简、脱敏的 HTML 结构，不保存账号 Cookie、密码或漫画图片。网络检查单独手动触发。
- GitHub Actions 在提交时执行测试和生成物一致性检查。生成文件也提交到 main，因此无需额外部署网站。
- 现有功能保持：1234 网页登录和权限查询、两个源的分类与入口设置。网站书架同步需要另行适配网站接口，不在本次仓库初始化中新增。
- 修复必须保留 source key、漫画 ID 和章节 ID 的规则；增加版本号后重新生成并推送。应用能否连接网站仍取决于用户网络和站点状态。

验证：现有 20 个源解析测试继续通过；增加发布地址、元数据一致性、非法配置、重复 key、语法错误、生成物过期的测试。
